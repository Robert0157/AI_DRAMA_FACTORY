# CEO 控台命名規則 v1（CEO 指示制定，2026-09-13）

> 適用範圍：`F:\AI_DRAMA_FACTORY\CEO\` **全樹**（所有子目錄與子目錄內全部檔案）。
> 本檔為**唯一權威**；`架構說明書_v16.1.md` §3.6／§8.4 與 `.github/copilot-instructions.md` §12.6 收錄摘要並指向本檔。

---

## 1. 通則

1. 編碼一律 UTF-8；繁中名稱允許；**不得含空白**。
2. **禁用字元**：`\ / : * ? " < > | ｜`（Windows／SMB／launchd 跨平台安全字集）。
3. 名稱長度 ≤ 60 字元；不以 `.` 或 `~$` 開頭（隱藏檔／Office 暫存檔違禁）。
4. 副檔名一律小寫：`.md` `.json` `.mp4` `.png` `.jpg` `.txt` `.html` `.xml`。
5. `CEO/` 為**呈現副本區**：命名在「複製進入」時套用本規則；產線原件（`Y:`）名稱不動，**禁止回流**。

## 2. 目錄命名

| 型 | 規則 | 範例 |
|---|---|---|
| 頂層分類 | `NN_<分類>`（NN＝01–99；新增分類需登錄本檔） | `01_劇本鑄造`、`02_素材與CP-D`、`03_樣片與交付`、`04_架構檢視`、`05_市場驗證`（2026-09-14 登錄） |
| 週期批次 | `YYYY-Www`（ISO 週） | `2026-W37` |
| 具名運行 | `<slug>-<N>`（小寫英數與連字號） | `timegate-56` |
| 運行階段衍生 | `<運行名>_phase<K>` | `timegate-56_phase1` |
| 審核／樣片包 | `<用途>_<主題>`（繁中或小寫 slug） | `音樂時間軸盲評`、`盲評2_療癒慢鏡`、`first_frames` |
| 證據集合 | 統一掛在 `04_架構檢視/驗證證據/` 之下：自動化＝純 `<RUNID>`；人工探針＝`<slug>_<RUNID 或 YYYYMMDD>` | `20260913T032202194316Z`、`tcc_probe_20260913`、`smoke_20260913T102245` |

## 4. 時間與 RUNID

- RUNID＝**UTC** `YYYYMMDDTHHMMSSZ`（與驗證器、smoke 一致）。
- 檔名禁止使用本地時間；跨機工件一律 UTC，避免 Mac／PC 時區歧義。
- 「人工探針」遠例：`<slug>_<YYYYMMDD>` 僅限無法自動生成 RUNID 的證據（如 `tcc_probe_20260913`），且須於本檔登錄。

## 5. 生成物邊界

- `CEO/README.md` 為 `scripts/common/ceo_console.py --sync` 之**生成物**：**禁止手改**；命名規則更新後必須重跑同步。
- `00_` 前綴保留給治理層手寫文件（本檔即 `00_命名規則.md`）。

## 6. 落地檢查

- 每次 `--sync` 前後：新進檔案是否符合本規則；不符者改名後再同步。
- 稽核方式：`git status` ＋ 本清單抽查；違規修正在當次提交內完成。
- 規則升版：建立 `00_命名規則_v2.md`（舊版保留，不覆寫）。
